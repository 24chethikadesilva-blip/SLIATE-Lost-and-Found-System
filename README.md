# SLIATE FIND - Campus Lost and Found Management System

## Files
- `index.html` - Home page
- `lost-items.html` - Lost item reports
- `found-items.html` - Found item reports
- `report-lost.html` / `report-found.html` - Report forms
- `login.html` / `register.html` - Login and registration screen previews
- `profile.html` - User profile preview
- `claim-status.html` - Claim status screen
- `admin.html` - Admin dashboard preview
- `security.html` - Security Room dashboard preview
- `contact.html` - Contact page
- `css/style.css` - Shared website design
- `js/script.js` - Shared page content and demo interactions

## Run
Open `index.html` in a browser, or upload the files to a GitHub repository and enable GitHub Pages.

## Important limitations
This is a front-end learning prototype. Reports are stored in the browser's localStorage on that device/browser only. It is not a real multi-user system. Login, registration, admin access, security access, claim approval and collection confirmation are NOT securely implemented. GitHub Pages cannot run PHP or MySQL. A real deployed system needs a secure backend, database, server-side validation, password hashing, role-based access control and private ownership verification.
